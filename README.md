# 🛡️ تطبيق تأكد (Ta-akad) - منصة الفحص والتعمية الذكية للبيانات الحساسة

> **الشعار:** تأكد — قبل ما تشارك

منصة ويب (مع تطبيق محمول أولي مبني بإطار عمل **Flutter**) مدعومة بنماذج الذكاء الاصطناعي الرؤيوي **Google Gemini 1.5**، مخصصة لفحص الصور والمستندات قبل مشاركتها أو نشرها على شبكات التواصل، واكتشاف محددات الهوية الوطنية السعودية وأرقام الجوال والآيبان ورموز QR وتشفيرها فورياً.

## 🚀 الشاشات الرئيسية الثلاث (User Journey)
1. **شاشة الماسح الذكي (Home / Scanner Screen):**
   - زر رفع المستند مع أيقونة درع متوهج متحرك.
   - مؤشر حالة جهوزية الدرع الأمني.
2. **شاشة نتائج التحليل الأمني (Analysis Result Screen):**
   - عرض المعاينة مع طبقة الإحداثيات (Bounding Boxes) الملونة حسب مستوى الخطر.
   - تقرير أمني مفصل لكل عنصر حساس.
   - شريط توعوي تفاعلي: *\"هذه المعلومة قد تُستخدم في انتحال الهوية، ننصح بإخفائها.\"*
3. **شاشة الحماية والإخفاء (Action & Output Screen):**
   - أدوات تعمية فورية: تمويه (Frosted Blur)، بكسلة (Pixelate)، شريط أسود عاتم (Black Bars).
   - إمكانية تفعيل أو إلغاء إخفاء أي عنصر بشكل مستقل.
   - زر المشاركة الآمنة الفورية (Share Safe Copy).

## 🤖 بنية استدعاء Gemini Multimodal Vision API

- **النموذج:** gemini-3.5-flash-lite، مع تبديل تلقائي إلى gemini-3.1-flash-lite ثم gemma-4-26b-a4b-it عند الضغط أو نفاد الحصة. السلسلة قابلة للتغيير عبر متغير البيئة GEMINI_MODELS.
- **السرعة:** نحو 5 ثوانٍ للفحص عبر Flash Lite. النموذج الاحتياطي Gemma (14,400 طلب/يوم مجاناً) يستغرق 60 إلى 80 ثانية ويُستخدم فقط إذا تعذّرت النماذج الأسرع.
- **نوع الاستجابة:** Structured JSON Output مع حقول الإحداثيات `[ymin, xmin, ymax, xmax]` على مقياس 0 إلى 1000 نسبةً لأبعاد الصورة.

## 🌐 نسخة الويب (الإصدار العامل حالياً)

المجلد `web/` يحتوي النسخة الفعلية من المنصة: واجهة HTML/CSS/JS وخادم Node بدون أي اعتماديات خارجية. المتصفح لا يتصل بـ Gemini مباشرة؛ الخادم هو من يحمل المفتاح ويستدعي النموذج عبر `POST /api/analyze`.

نسخة Flutter في `lib/` نموذج أولي لا يزال يعتمد على بيانات تجريبية.

### التشغيل محلياً

1. انسخ `.env.example` إلى `.env` وضع مفتاحك في `GEMINI_API_KEY`.
2. شغّل `npm start` ثم افتح <http://localhost:3000>.
3. للتأكد من قراءة المفتاح: `curl localhost:3000/healthz` يجب أن يعيد `"geminiKeyConfigured":true`.

يدعم الرفع: الصور (PNG, JPG)، مستندات PDF متعددة الصفحات، وملفات Word (DOCX).

### النشر

المنصة تحتاج استضافة تشغّل Node (Render أو Railway أو خادم خاص). الاستضافة الثابتة لا تكفي لأن `/api/analyze` لن يوجد فيها. ملف `package.json` موجود ليتعرف المضيف على المشروع كخدمة Node ويشغّل `npm start`. أضف `GEMINI_API_KEY` في إعدادات الاستضافة، ثم افحص `/healthz` قبل تجربة أي مسح.

### الخادم

- إصلاح انهيار الخادم عند الإقلاع (حرف زائد بعد نهاية الملف كان يسبب `ReferenceError`).
- المفتاح لم يعد مكتوباً داخل الكود؛ يُقرأ من متغير البيئة أو من `.env`. **المفتاح القديم منشور في تاريخ Git ويجب تدويره.**
- نقطة `/healthz` لفحص الحالة، ورسالة واضحة في الواجهة إذا كان المفتاح غير مضبوط.
- سجلات الخادم صارت بالإنجليزية. رسائل الواجهة تبقى عربية.

### واجهة الهاتف

- تخطيط جديد للشاشات الصغيرة (نقاط توقف 640 و400 بكسل): الأزرار بعرض كامل، شريط الخطوات يعرض اسم الخطوة الحالية فقط، ولا تمرير أفقي.
- أهداف اللمس 44 بكسل لجميع الأزرار والمفاتيح.
- ضبط الطباعة العربية: إلغاء التباعد السالب للأحرف، زيادة ارتفاع السطر، ومنع انفصال الكلمات اللاتينية (PDF, Word, IBAN) عن الكلمة العربية المرافقة لها.

### إمكانية الوصول

- دعم لوحة المفاتيح لبطاقات النتائج ومفاتيح الحجب، مع حلقات تركيز واضحة.
- تسميات ARIA لكل عنصر تفاعلي، واحترام `prefers-reduced-motion`.
- تباين الألوان 4.5:1 على الأقل في الوضعين الليلي والصباحي.

### إصلاحات

- نافذة اختيار الملف كانت تفتح مرتين.
- إعادة رفع نفس الملف كانت تُتجاهل بصمت؛ الآن تعمل، وتظهر رسالة خطأ إن فشلت قراءة الملف.
- التنبيهات: زر إغلاق (X)، مدة 2.6 ثانية، ولم تعد تعلق على حافة الشاشة.
